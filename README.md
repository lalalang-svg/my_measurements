# Мои измерения

Учебный прототип Android-приложения на Flutter для локального учёта пульса,
артериального давления и глюкозы. Данные хранятся в SQLite на устройстве.
Сервер, учётные записи и передача медицинских данных не используются.
Приложение не ставит диагнозов.

## Что находится в репозитории

- `lib/main.dart` — интерфейс ввода, история, сводка, локальная база,
  демонстрационные данные и сравнение с заданным пользователем ориентиром;
- `test/logic_test.dart` — проверки правил сравнения и ввода глюкозы;
- `pubspec.yaml` — зависимости Flutter, `sqflite`, `path`.

Каталоги Android и служебные файлы платформы создаёт установленный Flutter SDK.
После клонирования в корень репозитория:

```powershell
flutter create --platforms=android .
flutter pub get
flutter test
flutter run
```

В Android Studio можно открыть папку репозитория как Flutter-проект, выбрать
эмулятор и запустить `lib/main.dart`. Если команда `flutter` не находится
в терминале, укажите путь к установленному `flutter.bat` либо добавьте
папку `flutter\bin` в `PATH`.

## Проверяемые сценарии

1. На экране «Ввод» значок колбы загружает четыре учебные записи после
   подтверждения. Загрузка заменяет локальные записи, поэтому её не следует
   повторять после ввода собственных данных.
2. В «Истории» запись 03.03.2026 содержит глюкозу 5,6 ммоль/л без
   указанных условий. Сравнение недоступно.
3. Запись 04.03.2026 содержит 5,6 ммоль/л с контекстом «натощак».
   При учебном личном ориентире 5,5 ммоль/л выводится сообщение о превышении
   этого ориентира. Число 5,5 здесь является примером настройки,
   а не медицинской рекомендацией.
4. На «Сводке» четыре записи дают средний пульс 76,3 уд/мин и среднее
   давление 125,8/82,8 мм рт. ст. Глюкоза с различными условиями
   не объединяется в одно среднее.
5. Можно сохранить запись только с пульсом. После перезапуска приложения
   локальные записи остаются; отсутствующие поля не включаются в среднее.

Проверки `flutter test` входят в исходники. Сборка debug APK и запуск
приложения на эмуляторе Android проводились отдельно. Повторная сборка
из этого архива в текущем окружении не проводилась.

## Ограничения

Локальная база не синхронизируется между устройствами. Удаление приложения
может удалить сохранённые записи. В приложении нет экспорта, шифрования базы,
профилей нескольких пользователей и медицинской интерпретации показателей.
